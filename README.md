# Tornevall Tools - public support and changelog

This repository is the public support entrypoint for [Tornevall Tools](https://tools.tornevall.net/).

The application source code, infrastructure and operational configuration are intentionally not published here. This repository is for users who want to report a bug, request an improvement, or follow user-visible changes without exposing internal implementation details.

## Report a bug or request a feature

Open an issue in this repository:

https://github.com/Tornevall/tools.tornevall.net/issues

For feedback that fits the built-in Tools feedback flow, you can also use the public suggestion board:

https://tools.tornevall.net/suggestions

A useful report normally includes what you were trying to do, what you expected, what happened instead, and which Tools service or page is affected. Do not post passwords, API tokens, private credentials, sensitive personal data or other secrets.

## What happens after a report is accepted?

Issues stay open here while they are waiting in the public intake queue.

When an issue is actually taken up for implementation, it is transferred to the private implementation tracker. The public issue then receives an **in progress** note and is closed here. In this repository, that closure means that active work has moved to the internal tracker - it does **not** mean the change is already released.

Internal issue URLs, implementation details and infrastructure are deliberately not exposed from the public ticket.

## Follow changes

User-visible Tools changes are summarized in [CHANGELOG.md](CHANGELOG.md).

You can also browse the live Tools service catalogue at:

https://tools.tornevall.net/services

## Repository scope

This repository intentionally contains only public documentation and issue tracking. It does not contain the Tornevall Tools application source code.
